# limfosan

Repositorio para proyecto de Limfosan Ltda.

## Contenido

- `TallerAyDS/` — Proyecto **Truco** para la asignatura "Análisis y Diseño de Sistemas" (Node.js / Express / MongoDB). Ver su [README](TallerAyDS/README.md).
- `app/` — Nueva plataforma de juegos de cartas (Truco primero): monorepo Node 24 + React + PostgreSQL. Ver su [README](app/README.md).
- `docs/` — Documentación de producto y planificación. Ver el [Plan maestro de la plataforma de juegos de cartas](docs/plan-plataforma-juegos-de-cartas.md).
